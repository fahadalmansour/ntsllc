## Execution Flow

```
1. New prospect → sign Mutual NDA (optional but recommended)
2. Scoping call → agree scope
3. Send Proposal
4. Client accepts → sign MSA (once per client relationship)
5. Per project → sign SOW (references MSA)
6. Engage freelancers → sign Subcontractor Agreement + Exhibit A per project
7. Enterprise / retainer → sign SLA (after first project completes)
```
